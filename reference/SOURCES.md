# Reference sources

These works informed research and methodology. HYDRA does not include their
full text; use authorized editions or publisher sources.

- *The Web Application Hacker's Handbook* — Dafydd Stuttard and Marcus Pinto.
- *The Tangled Web* — Michal Zalewski.
- *Bug Bounty Bootcamp* — Vickie Li.
- *Black Hat Python*, second edition — Justin Seitz and Tim Arnold.
- *JavaScript for Hackers* — Gareth Heyes.
- OWASP Web Application Penetration Testing Checklist.
- Zseano's Bug Hunter Methodology.
- Bug Hunters Methodology Live: Recon and App Analysis.
- Bypassing Cloudflare WAF in Bug Bounty Programs.
- ChatGPT for Offensive Security.

References are bibliographic pointers only, not a license to reproduce the
works.
