# Bug Bounty Hunting Skill (Community Methodology)

## Phase 0: Session Setup
- Source ~/.proxyenv for Tor proxy
- Verify Tor: `proxychains4 curl https://check.torproject.org/ | grep -o "Congratulations"`
- Run full pipeline: CHAOS → HTTPX → NAABU → NMAP + PARSERS → NUCLEI → FFUF
- Set OUTDIR=~/recon_reports/companies/<program>/unreported/
- Save all findings with hash dedup

## Phase 1: Passive Reconnaissance (Subdomain Discovery)
- **subfinder**: `subfinder -d target.com -all -recursive -silent -o subs.txt`
- **chaos**: `chaos -d target.com -o chaos_subs.txt`
- **assetfinder**: `assetfinder --subs-only target.com >> subs.txt`
- **crt.sh**: `curl -sk "https://crt.sh/?q=%25.target.com&output=json" | jq -r '.[].name_value' | sed 's/*.//g; s/\\n/\n/g' | sort -u >> subs.txt`
- **CertSpotter**: CertSpotter API for fresh certs
- **Combine**: `cat subs.txt chaos_subs.txt | sort -u | dnsx -silent -o resolved.txt`

## Phase 2: Active Reconnaissance (Live Hosts + Port Scan)
- **HTTPX**: `httpx -l resolved.txt -ports 80,443,8080,8443,3000,5000,8000,8888,9000 -silent -o live.txt`
- **CDN Filtering**: `httpx -l ip.txt -title -silent | grep -vi "cloudflare|akamai|fastly" | awk '{print $1}' > origin_ips.txt`
- **Naabu**: `naabu -l origin_ips.txt -top-ports 1000 -rate 1500 -verify -silent -o naabu.txt`
- **Nmap**: `python3 ~/scripts/naabutonmap.py -i naabu.txt -o nmap_scan/`
- **Nuclei**: `cat ip.txt | nuclei -tags cve -bs 200 && cat naabu.txt | nuclei -tags cve -bs 200`
- **FFUF**: `ffuf -w naabu.txt:URL -w ~/payloads/backup_files_only.txt:FILE -u https://URL/FILE -mc 200 -rate 50 -fs 0`

## Phase 3: URL Collection & Analysis
- **gau**: `gau --subs target.com | uro > urls.txt`
- **waybackurls**: `waybackurls target.com >> urls.txt`
- **AlienVault**: `~/scripts/alienvault.sh target.com >> urls.txt`
- **URLScan.io**: `curl -s "https://urlscan.io/api/v1/search/?q=domain:target.com"`
- **VirusTotal**: `curl -s "https://www.virustotal.com/ui/domains/target.com/urls"`
- **Filter params**: `cat all_urls.txt | uro | grep -E '\?[^=]+=.+$' > params.txt`
- **Parameter Pattern Analysis**:
  - `url=, src=, dest=, webhook=, callback=` → SSRF
  - `file=, page=, template=, path=, include=, load=` → LFI/RFI
  - `id=, user_id=, order=, invoice=, account=` → IDOR
  - `redirect=, next=, returnTo=, goto=, url=` → Open Redirect
  - `q=, search=, name=, title=, comment=, message=` → XSS/SSTI/SQLi
  - `cmd=, exec=, shell=, ping=, host=, command=` → Command Injection

## Phase 4: JS Bundle Analysis

- **All API key patterns**: Google AIza[0-9A-Za-z_-]{35}, Stripe sk_live_/pk_live_, AWS AKIA[0-9A-Z]{16}, GitHub ghp_, Slack xox[baprs]-, JWT eyJ[a-zA-Z0-9_-]+\.eyJ
- **Razorpay**: rzp_live_|rzp_test_ prefixes
- **Validate keys**: curl against vendor API to check active status
- **Referer bypass**: Add referer header to bypass key restrictions
- **Extract JS**: `cat all_urls.txt | grep "\.js$" | httpx -silent > js_files.txt`
- **Secret Scanning**:
  - Google API Keys: `grep -oP 'AIza[0-9A-Za-z_-]{35}'`
  - Stripe Keys: `grep -oP 'sk_live_|pk_live_[0-9a-zA-Z]+'`
  - AWS Keys: `grep -oP 'AKIA[0-9A-Z]{16}'`
  - GitHub Tokens: `grep -oP 'ghp_[0-9a-zA-Z]{36}'`
  - Slack Tokens: `grep -oP 'xox[baprs]-[0-9a-zA-Z-]+'`
  - JWT Tokens: `grep -oP 'eyJ[a-zA-Z0-9_-]+\.eyJ[a-zA-Z0-9_-]+\.[a-zA-Z0-9_-]+'`
- **API Endpoint Extraction**: `grep -oP '(?<=["'"'"'])https?://[^"'"'"' ]+' | sort -u`
- **React/Next.js Specific**:
  - `__NEXT_DATA__` for full route list
  - `_buildManifest.js` for page enumeration
  - Source maps for internal routing + API endpoints

## Phase 5: Vulnerability Discovery

### Phase 5: Vulnerability Discovery (Priority Order)
1. Subdomain Takeover — nuclei -t takeovers/
2. CORS — curl -I -H "Origin: https://evil.com"
3. Spring Boot Actuator — /actuator, /actuator/env, /actuator/heapdump
4. Config files — .env, .git/config, dump.sql
5. SQLi — ' OR '1'='1, UNION SELECT, SLEEP
6. XSS — <script>, <img onerror>, <svg onload>
7. SSRF — collaborator, 169.254.169.254, file:///
8. IDOR — sequential IDs 1,2,100,500,1000
9. GraphQL — {"query":"{__schema{types{name}}}"}
10. Auth Bypass — null/empty tokens, X-Forwarded-For, X-Internal-Request

**Priority**: RCE > SQLi > Auth Bypass > SSRF > IDOR > XSS > Info Disclosure
## Phase 6: WAF Bypass Techniques (Ordered)
1. **URL encode** the payload
2. **Double URL encode**
3. **Comment injection**: `UN/**/ION SE/**/LECT`
4. **Whitespace alternatives**: `%0A`, `%09`, `%0D`, `%A0`
5. **HPP** (HTTP Parameter Pollution)
6. **Content-Type confusion**: JSON vs XML vs form
7. **Chunked transfer encoding**
8. **Body padding**: junk to exceed WAF inspection window
9. **Protocol downgrade**: HTTP/2 → HTTP/1.0
10. **Case randomization**: `uNiOn SeLeCt`
11. **Unicode normalization**: fullwidth, overlong UTF-8
12. **Origin IP discovery**: shodan, historical DNS, email headers, cert transparency

## Phase 8: Tech-Specific Vectors

- **Laravel**: /.env, /debug, Ignition RCE (CVE-2021-3129), APP_KEY exploit for RCE via Ignition solution
- Debug mode signs: Full stack traces with server paths, Symfony error pages, vendor paths exposed
- **Spring Boot**: Actuator endpoints (priority: /env, /heapdump, /jolokia for RCE)
- **Laravel**: `/.env`, `/debug`, Ignition RCE (CVE-2021-3129), APP_KEY exploit
- **Django**: `/admin/`, `DEBUG=True`, SECRET_KEY exposure
- **Next.js**: `__NEXT_DATA__`, React2Shell (CVE-2025-55182), RSC Flight protocol
- **React SPA**: JS bundle → API routes → test all discovered endpoints
- **Mendix**: `get_session_data`, SOAP service discovery, XAS session extraction
- **IIS**: shortname (tilde) scanning, viewstate RCE, `web.config` leak, `/trace.axd`
- **GraphQL**: introspection, batching, depth limit bypass, query whitelist bypass
- **Express/Node**: prototype pollution, `/.env`, `/debug`
- **Apache**: `/server-status`, `/server-info`, `.htaccess` bypass
- **Nginx**: `alias` traversal, `merge_slashes` bypass

## Phase 9: Vulnerability Chaining
- SSRF (Med) + Internal Service (Low) = RCE (Critical)
- Auth Bypass (Med) + IDOR (Med) = Data Exfil (Critical)
- XSS (Med) + CSRF (Med) = Admin Action (Critical)
- Info Disclosure (Low) + Cred Reuse (Low) = ATO (Critical)
- Open Redirect (Med) + OAuth Token Theft (Med) = ATO (Critical)

## Phase 10: Reporting

- Include: working curl commands, CVSS vector, CWE reference

- Show blocked vs bypassed endpoints side-by-side
- Impact must be specific (what attacker can do, how many users affected)
